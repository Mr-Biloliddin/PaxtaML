# Oq Oltin — ИИ-мониторинг хлопка

> **Oq Oltin** («белое золото») помогает агроному раньше замечать болезни хлопка и понимать,
> что проверить в поле. Сейчас работает ИИ-диагностика болезней по фото листа.
> Остальные разделы — макет будущей системы мониторинга полей.

---

## 1. Проблема и решение

**Проблема.** Болезни хлопка (вилт, бактериальный ожог, пятнистости) замечают поздно: когда
очаг уже виден глазом, часть урожая потеряна. Агроном физически не успевает регулярно
осматривать сотни гектаров.

**Решение.** Агроном или фермер фотографирует лист на телефон. Через доли секунды система говорит:
- здоров лист или нет;
- какая болезнь вероятнее всего;
- насколько ИИ уверен в ответе;
- что проверить и сделать в поле.

**Ценность.** Раннее обнаружение, точечные меры вместо обработки всего поля, меньше потерь урожая.

## 3. ИИ-модель

### Что распознаёт

| Класс в датасете | На сайте | Что это |
|---|---|---|
| Healthy Leaf | Здоровый лист | Признаков болезни нет |
| Alternaria Leaf Spot | Альтернариоз | Грибковая пятнистость листьев |
| Bacterial Blight | Бактериальный ожог (гоммоз) | Бактериальная инфекция |
| Fusarium Wilt | Фузариозный вилт | Почвенный гриб, увядание |
| Verticillium Wilt | Вертициллёзный вилт | Почвенный гриб, одна из главных болезней хлопка в Узбекистане |

### Как устроена

- **Датасет:** Cotton Leaf Image Dataset, используется только `Cotton_Original_Dataset`.
  Аугментированные копии исключены намеренно: иначе копии одного фото попали бы и в обучение,
  и в проверку, и точность оказалась бы завышенной.
- **Разбиение:** 70% обучение / 15% проверка (val) / 15% тест (test): 969 / 202 / 202 фото.
- **Модель:** EfficientNet-B0 (≈5 млн параметров), дообучена с весов ImageNet (transfer learning).
- **Обучение:** GPU NVIDIA RTX 4060 Laptop, около 4 секунд на эпоху, ранняя остановка на 18-й эпохе.
- **Аугментации:** повороты, отражения, обрезка, изменение яркости и цвета (имитация условий поля).

### Результаты на тестовых фото (модель их не видела)

| Показатель | Значение |
|---|---|
| **Верных ответов** | **195 из 202 — 96,5%** |
| Больных листьев отмечено как больные | 153 из 153 — ни одного пропуска |
| Ложных тревог на здоровых листьях | 0 из 49 |
| Macro F1 | 96,1% |

По классам (верно / всего):

| Класс | Результат |
|---|---|
| Здоровый лист | 49 / 49 |
| Фузариозный вилт | 49 / 50 |
| Вертициллёзный вилт | 45 / 46 |
| Альтернариоз | 23 / 25 |
| Бактериальный ожог | 29 / 32 |

**Вывод:** модель надёжно отличает здоровый лист от больного. Ошибки бывают только между
похожими болезнями, поэтому система даёт агроному **сигнал и чек-лист для проверки**,
а не окончательный диагноз.

## 4. Сайт: что где

Запуск: `python app/server.py`, затем открыть http://127.0.0.1:8000

| Страница | Что показывает | Данные |
|---|---|---|
| **ИИ-анализ** | Загрузка фото → «здоров / болезнь», уверенность, что делать агроному, «Как это работает», «Насколько ИИ можно доверять», история проверок, технические детали (свёрнуты) | **Реальные** |
| Обзор | Площадь, высота растений, NDVI, прогноз урожая, состояние полей, уведомления, погода | Демо |
| Поля | Карточка поля: фазы развития, показатели, фотодневник | Демо |
| Фитосанитария | Очаги болезней, карта риска по полям, факторы риска | Демо (блок «Последние распознавания» — реальный) |

Возможности страницы ИИ-анализа:
- фото можно загрузить кнопкой, перетащить в окно или вставить через Ctrl+V;
- с телефона в той же Wi-Fi сети: `python app/server.py --host 0.0.0.0` → `http://<IP ноутбука>:8000`, затем сразу снимать камерой;
- история проверок и фото сохраняются в `runs/app/`.

## 6. Быстрый старт (Windows)

```powershell
git clone -b main https://github.com/Mr-Biloliddin/PaxtaML.git
cd PaxtaML
install_gpu.bat                         # окружение + PyTorch с CUDA
.venv\Scripts\activate

# датасет положить в папку проекта, затем:
python scripts\split_dataset.py --src "Cotton Leaf Image Dataset\Cotton_Original_Dataset"
python src\train.py                     # ~3 минуты на RTX 4060
python src\evaluate.py --weights runs\growth_stage\<дата>\best.pt
python app\server.py                    # http://127.0.0.1:8000
```

Частые проблемы:
- **«running scripts is disabled»** → `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`
- **«paging file is too small» / зависает загрузка данных** → в `configs/train.yaml` поставить `num_workers: 0`
- **нет интернета на площадке** → сайт работает, просто с системными шрифтами

## 8. Ограничения (честно)

- Датасет относительно небольшой (~1400 фото). В тесте 25–50 фото на класс, поэтому одна ошибка сдвигает метрику класса на 2–4%.
- Фото в датасете в основном крупные планы листа. На фото с дрона или всего растения точность может быть ниже.
- Модель знает только 5 классов. Вредителей (совка, клещ, тля) и дефицит питания она не распознаёт.
- По фото нельзя назначать дозы препаратов и удобрений. Для этого нужны анализ почвы, стадия развития, погода и история обработок.
- Страницы «Обзор», «Поля», «Фитосанитария» пока на демо-данных.

## 10. Вопросы жюри: короткие ответы

**Где здесь ИИ?**
Нейросеть EfficientNet-B0 обучена на фото листьев хлопка и распознаёт 4 болезни и здоровый лист.
Проверена на 202 фото, которые не видела: 96,5% верных ответов.

**Можно ли верить 96,5%?**
Это результат на отдельной тестовой выборке, которая не участвовала ни в обучении, ни в выборе модели.
Аугментированные копии исключены, чтобы не было утечки.

**Что если ИИ ошибётся?**
На тесте ни один больной лист не был назван здоровым. Ошибки были только между похожими болезнями.
Поэтому система не ставит окончательный диагноз, а даёт агроному сигнал и чек-лист. При низкой уверенности (<60%) она прямо просит переснять фото и проверить вручную.

**Почему не говорите, сколько удобрений вносить?**
По одному фото это невозможно определить корректно. Для доз нужны анализ почвы, стадия, погода и история внесения.

**Демо-страницы — это настоящие данные?**
Нет, они помечены «демо-данные» и показывают, как будет выглядеть полная система.
Настоящая часть — ИИ-анализ фото и история проверок.

**Сколько стоит внедрение?**
Модель работает на обычном ноутбуке и даже без видеокарты. Спутниковые и погодные данные для следующего этапа бесплатные (Sentinel-2, Open-Meteo).
